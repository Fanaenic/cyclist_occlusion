# Совокупность целей для кривой деградации

Основная совокупность (`matching.population: all_levels`): цели, которые ни на одном уровне не закрыты масками соседей сверх 10% площади; остальные — ignore на всех уровнях. Так кривая 0→90 % строится по одним и тем же объектам. Вариант «по уровню» (исключение только на своём уровне) — дополнительный отчёт.
