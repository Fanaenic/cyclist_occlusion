# Использование тестовых данных в пилотах

По сохранённым спискам и файлам YOLO-разметки все 200 тестовых кадров пилота каждого датасета находятся в текущей части test. В выборке пилота BDD100K — 239 из 267 целей, в KITTI — 170 из 170. Логи и сохранённые результаты показывают, что на этих кадрах рассчитывались метрики. Эти сведения относятся к оценке моделей.

После раннего пилота с шумовой заливкой на KITTI в протоколе появились фоновая заливка, приманки и контроль заплаток. В следующих пилотах KITTI сравнивались варианты масок и их влияние на Recall и срабатывания на фоне. Для BDD100K сохранены метрики раннего пилота на test. По имеющимся выходам нельзя установить, какие именно результаты BDD100K использовались при выборе каждой правки.

Оценка на текущем test BDD100K получает описательный статус. Для подтверждающей проверки понадобится отдельно зафиксированная выборка, ранее не использованная при разработке. Новые технические прогоны используют calib. Параметры каждого нового прогона сохраняются вместе со списками кадров.
