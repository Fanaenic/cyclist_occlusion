# Воспроизведение технического пилота KITTI

Пакет повторяет расчёт контраста proposed против baseline на calib от сохранённых детекций после сопоставления с разметкой до итогового решения. Входы взяты из прогона `smoke_calib_kittti_2x2`. Для контроля используются сохранённые числа срабатываний на заплатках по seed. Пакет не включает повторный инференс, обучение и вторичные контрасты схемы 2×2.

Из корня проекта в PowerShell:

```powershell
.\.venv\Scripts\python.exe repro/kitti_calib/replay.py
```

Требуются NumPy и PyYAML из окружения проекта. Скрипт пересчитывает статистику и сравнивает полученный объект итогового решения с `expected.json`. Новые отчёты записываются в `runs/replay_kitti_calib`.

Проверка воспроизведения выполнена в PowerShell. Итоговое решение совпало с сохранённым `expected.json`.
